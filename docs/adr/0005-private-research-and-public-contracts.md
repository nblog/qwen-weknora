# ADR-0005：私有研究目录排除与公开测试契约

- 状态：已接受
- 日期：2026-11-12
- 决策主体：用户明确要求 `.codex-tracking/.gitignore` 内容为 `*`，不公开该目录，并将远端历史重建为一个 first commit。

## 背景

研究目录可能包含不公开的信息，不能作为公开仓库或其历史的一部分。此前测试直接读取该目录中的上游 schema 与 REST fixture；仅停止跟踪目录会导致干净 clone 无法运行测试。

## 决策

1. `.codex-tracking/` 仅保留在本机。其内部忽略文件写入 `*`，根 `.gitignore` 同时排除整个目录；内部忽略文件本身也不提交，确保公开树完全不包含该目录。
2. 仅将已公开的两份 Agent Plugins 1.0.0 官方 schema、WeKnora REST fixture 及所需许可证保存到 [`test/_shared/upstream/`](../../test/_shared/upstream/README.md)。不复制研究报告、会话、工具执行证据或其他私有资料。
3. 这些公开契约逐字节来自固定上游版本，来源、SHA-256 与许可证在该目录统一维护。测试直接引用它们，公开测试不依赖私有目录；旧本地研究快照只作历史资料，不再是测试输入。
4. 本决策更新 [ADR-0004](0004-tool-contract-authority.md) 的 fixture 存放与引用方式，保留其“一个有效契约来源”的原则，不改变 REST、MCP 或配置语义。
5. 公开文档引用公开契约、正式验收记录或官方上游来源；私有执行记录不提供仓库内链接。研究与验收的历史事实不伪造、不改成未执行。
6. 在保留本地资料的前提下，为公开文件树创建无父提交的 `Initial commit`，以带明确旧 SHA 的 force-with-lease 更新 `main`。只重写用户授权的远端分支，不删除本地研究文件或其他 worktree。

## 验证与边界

- 检查新提交树、远端分支/标签、提交父节点和远端目录 API；从不含私有目录的导出内容运行全部测试。
- 发布包继续使用显式白名单，不包含研究目录或测试契约。
- 重写 Git 引用不等同于服务器物理擦除；GitHub 可能保留不可达对象或缓存。最终回报必须区分当前公开历史/文件树与平台缓存，不能承诺未验证的删除效果。
